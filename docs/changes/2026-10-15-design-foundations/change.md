# 작업: 디자인 토큰과 스탠드얼론 미리보기

- 상태: 완료, 사용자 시각 검토 대기
- 요청 근거: 라이트 모드 톤앤매너와 원칙에 맞는 구체적인 토큰을 작업하고, 확인 가능한 스탠드얼론 HTML을 만들어 달라는 요청.
- 기준: main, 20136d3. 이전 DESIGN.md 커밋은 원격 푸시 자동 승인 거절로 로컬에만 존재한다.
- 실행 범위: 토큰 구현안과 로컬 미리보기, 관련 문서 및 검증. 원격 푸시는 이전 승인 검토에서 보류된 상태를 유지한다.
- 마지막 확인: 2026-10-15

## 계획

1. 기존 primary, 폰트, 타이포그래피와 간격 기본값을 유지하고 팔레트, 의미별 상태, 크기, 그림자, 모션을 구체화한다.
2. packages/design-tokens/src/theme.css를 원본으로 삼아 docs/design-foundations.html에 CSS와 폰트를 내장한다. 재생성 도구와 템플릿은 기존 packages/design-tokens/에 둔다.
3. 미리보기에서 색상, 글자, 간격, 형태, 동작을 확인하고 인터랙션 및 키보드, 좁은 화면을 검증한다.
4. 기본 검사와 독립 UX 문구 검수를 수행한다.

## 완료 조건

- HTML 파일 하나를 열면 네트워크 없이 폰트, 스타일, 동작을 확인할 수 있다.
- 미리보기의 토큰 값은 공통 CSS와 일치한다.
- 기본 primary와 폰트는 유지하며, 세부 토큰은 사용자 검토를 위한 구현안으로 제시한다.
- DESIGN.md의 방향과 사용자의 정보 절제 원칙을 따른다.

## 진행과 인계

- 공통 CSS 토큰과 재생성 가능한 스탠드얼론 HTML 구현 완료.
- 구체적인 값에 대한 최종 시각 검토는 사용자가 미리보기를 확인한 뒤 진행한다.

## 검증 결과

- `pnpm check` 통과: lint, 웹·플러그인 타입 검사, 양쪽 빌드 완료. 폰트 내장 HTML이 기본 1MiB 검사 한도를 넘는 경고 1건이 있어 `pnpm exec biome check --files-max-size=7000000 docs/design-foundations.html`로 생성 파일도 별도 검사했고 통과했다.
- primary 위 흰색 텍스트 대비 6.96:1. 보조 텍스트와 상태 텍스트 7개 조합은 4.5:1 이상, 컨트롤 경계는 표면과 3:1 이상 확인.
- 브라우저에서 색상 선택, 샘플 문장 변경, 여백 조절, 모션 재생·감소, Enter 조작, 2px 키보드 포커스, 다이얼로그 열기·Escape 닫기, 입력 초기화 및 CSS 다운로드 확인. 브라우저 오류 로그 없음.
- 390px 화면에서 6개 분류의 페이지 가로 넘침 없음. 메뉴 자체는 가로 스크롤로 접근.
- HTML의 외부 스타일·스크립트·폰트 요청이 없음을 정적 검사. 공통 CSS와 내장 CSS, 다운로드 CSS 일치 및 재생성 결과 동일 확인.
- 브라우저 도구는 file 프로토콜을 허용하지 않아 파일 직접 열기 실행 검증은 수행하지 못했다. 로컬 HTTP에서 렌더링과 동작을 확인했다.
- 독립 `ux-writing-review` 에이전트(gpt-6-luna, high)가 신규 템플릿 전체의 문구·표시 조건·접근성 이름을 코드 기반으로 검수: 문제 없음. 해당 에이전트는 실행 화면을 검수하지 않았으며 화면 검증은 메인 에이전트가 수행했다.
- 새로운 폴더는 허용된 작업 기록 폴더만 사용. 빌드 산출물은 기존 승인 경로에 생성했고 임시 파일은 저장소에 추가하지 않았다.

## 반영 범위

- DESIGN.md와 README에 미리보기를 연결하고 구조 문서의 현재 토큰 구현 상태를 갱신했다.
- 앱 화면이나 공통 UI 컴포넌트의 구조·문구는 변경하지 않았다. 기존 토큰의 의미별 색상이 새 팔레트를 참조하므로 이를 사용하는 앱의 색상도 변경된다. 기존 컴포넌트의 모든 치수·전환을 새 토큰으로 이관하는 작업은 포함하지 않았다.
- 로컬 결과이며 원격 푸시, PR, 배포는 수행하지 않았다. 이전 기본 브랜치 푸시의 자동 승인 거절 이후 추가 푸시 승인은 받지 않았다.
