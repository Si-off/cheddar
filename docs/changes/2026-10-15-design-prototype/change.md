# 작업: 독립 웹 디자인 시안

- 상태: 구현 중
- 요청과 결정의 근거: 사용자가 디자인 토큰만 공유하는 독립 로컬 웹 시안, 핵심 업무 흐름, 자유로운 레이아웃·모션 재설계를 선택했다. 전용 소스 폴더와 구조 문서 반영을 명시적으로 승인했고 사용자 플로우 전체 재설계를 위임했다.
- 실행 범위: 시안 구현·로컬 검증·커밋·일반 푸시. PR·병합·배포 제외.
- 기준 브랜치·커밋: `codex/mvp-generation`, `67fca753680ba968135b3313389c15aff958188c`
- 작업 경로: `apps/web/src/design-prototype/`, `apps/web/design-prototype.html`
- 마지막 확인 일자: 2026-10-15

## 의도와 결정

- QA 테스트 준비 → 근거 화면 선택 → 샘플 생성 → 케이스 편집·후보 검토 흐름을 독립적으로 설계한다.
- 커머스 구매 흐름의 샘플 데이터로 동작한다. 실제 API·AI·기존 공통 UI에 의존하지 않는다.
- React·Motion·Vite와 기존 디자인 토큰을 사용한다. 색·서체·간격·모서리·깊이·모션 값은 토큰에서 가져온다.
- 패널 이동·레이아웃 전환과 모션 감소 지원은 시안 전용 선택이다. DESIGN.md와 토큰 원본은 변경하지 않는다.
- 브라우저 저장·복원, 실패 시 입력 보존, 후보 중복 반영 방지, 삭제 복원을 지원한다.
- 실제 공유·XLSX·인증·백엔드 연동은 제외한다. 외부 배포하지 않는다.

## 구현·검증 계획

- 시작 화면, 테스트 준비, 편집 작업 공간과 전용 로컬 모델을 구현한다.
- 전환·선택·생성·후보 반영에 연결된 모션을 제공한다.
- Playwright로 핵심 흐름·실패·복원·키보드 동작을 검증하고 크기별 실행 화면을 확인한다.
- 루트 lint·typecheck·build와 지정 독립 UX 문구 검수를 수행한다.
- 임시 로그·스크린샷·테스트 결과는 OS 임시 경로만 사용한다.

## 진행과 인계

- 기존 백엔드 생성 코드·테스트와 MVP 작업 기록에 다른 작업의 변경이 있으며 수정·커밋 대상에서 제외한다.
- 완료 여부·검증 결과·원격 반영은 구현 후 기록한다.
