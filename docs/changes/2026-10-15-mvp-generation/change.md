- 사용자가 키 입력 후 기존 DB 설정 연결·migration 적용·API 재시작을 요청했다. migration 4건 적용 상태, API 3102·최신 웹 5173 HTTP 200과 준비 상태 확인. 기존 DB·파일 저장소와 입력한 키를 보존했다. 사용자가 종료한 이전 웹 5175는 종료 상태로 유지했다.
