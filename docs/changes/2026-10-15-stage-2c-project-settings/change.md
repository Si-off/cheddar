## 공통 계약 수신 후 API 구현

- 조율 담당의 `ff4e09c`를 기존 문서 커밋을 보존하며 merge했다(`01f5cff`). IA/양식 schema·DTO·초기화·테스트 helper와 승인 경로를 수용했다. 이후 공통 `493bf31`은 2A API 통합·Playwright 검색 경로 확장으로 안내받았으며 후속 연결 시 수용한다.
- 승인된 `apps/api/src/ia/`, `apps/api/src/templates/`에 module/controller/service/repository를 추가했다. IA 목록·등록·부분 수정·revision 삭제, 트리 순환/프로젝트 경계/중복·참조 검사와 양식 전체 저장·열 식별자 보존을 구현했다.
- `TemplatesModule`은 `TemplatesRepository`를 export한다. `readSnapshot(tx: DatabaseTransaction, projectId: string): Promise<ProjectTemplateDto>`는 같은 tx에서 저장 양식을 읽고 생성하지 않는다. 호출자는 프로젝트 행 잠금을 먼저 획득한다.
- 기본 양식 초기 열과 사용자 열 너비는 공통 계약의 180을 따른다. 양식 원본 UUID는 유지하고 시트 복사 때만 2B가 새 UUID/view 매핑을 만든다.
- 조율 담당의 전용 DB 슬롯을 받아 기존 환경 파일을 node --env-file로 프로세스에만 전달했다. `pnpm test:api` 전체 35개 통과(실패·skip 0). 슬롯 반환 메시지를 전달했다. 실행 DB migration과 상시 서버는 실행하지 않았다.
- 첫 HTTP 테스트에서 DELETE query DTO가 type-only import로 바뀌며 런타임 검증 메타데이터가 사라진 것을 발견했다. `ApiExtraModels`의 실제 값 참조로 수정한 뒤 동일 회귀 테스트를 포함해 통과했다.
- `pnpm check` 통과. 공통 `shared-schema.test.ts` optional-chain 제안과 기존 디자인 HTML 크기 경고 두 건은 유지한다. 2C 소유 파일 Biome 검사는 경고 없이 통과했다.
- API 신규 오류 문구는 지정 독립 에이전트가 IA/양식 서비스·발생 조건·DTO·공통 오류 전달 코드를 검수해 문제 없음으로 보고했다. 중복·참조·충돌의 조건과 대응 정보를 유지했고 제거·축약 항목은 없다. 실제 웹 표시·초안 보존은 이번 문구 검수 범위 밖이다. API 등록·실제 명세·SDK는 조율 담당에게 이 기능 커밋을 전달한 뒤 연결한다. 웹 기능·시트 복사 교차 검증은 아직 미완료다.
