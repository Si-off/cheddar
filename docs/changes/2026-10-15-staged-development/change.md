## 단계 시작과 인계

각 단계마다 다음 내용을 정리한 뒤 작업 채팅을 준비한다.

1. 사용자 요청 범위와 완료 기준, 아직 결정할 사항.
2. 선행 결과의 브랜치·커밋, 자신의 worktree·브랜치.
3. 담당 모듈·파일과 다른 채팅이 소유하는 공통 파일.
4. API·이벤트·데이터 계약의 기준 커밋과 대표 입력·출력.
5. 실제 검증 명령, 실행 환경, UX 문구 검수 적용 여부.
6. 보고할 결과: 변경 커밋, 원격 반영, 테스트 결과, 미확인 사항, 통합 순서.

작업 채팅은 자신의 변경을 검증·커밋·일반 푸시한다. 조율 채팅은 결과와 계약 차이를 확인하고 통합 순서를 정한다. 단계 시작 권한을 PR 병합·배포 권한으로 확대하지 않는다.

공통 계약 파일과 마이그레이션 생성의 담당은 한 채팅으로 정한다. 다른 채팅은 변경 필요성을 전달하며, 각자 다른 계약을 확정하거나 다른 worktree를 직접 수정하지 않는다. 변경된 계약은 커밋 단위로 전달하고 통합 검증한다.
