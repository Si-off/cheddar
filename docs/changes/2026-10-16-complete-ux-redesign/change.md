## 확정된 경험

- 시트 한 화면에서 생성·편집·자료 확인을 이어간다. 별도 생성 결과 페이지나 탭을 만들지 않는다.
- 명확한 생성 케이스는 서버에서 원자적으로 추가·저장한다. 기존 데이터·양식·번호·근거 연결을 보존하고 완료 후 바로 일반 행으로 편집한다.
- 불확실한 항목만 사용자가 여는 확인 모달에서 답변·수정·추가·제외한다. 중간 저장 단계를 없애고 수정 초안을 보존한다.
- 프로젝트·시나리오 목록, Figma 자료, 프로젝트 설정과 읽기 전용 미리보기를 함께 개편한다.
- 플러그인은 실제 경량 썸네일, 프로젝트 검색, 단계별 상태, 업로드 후 웹 열기를 제공한다.
- 보라 `#515299`·청록·Noto Sans/KR의 라이트 정체성을 유지한다. 툴바 32px, 폼 40px, 표 최소 행 48px를 토큰으로 관리한다.
- 의미 있는 모션을 120/180/240ms로 통일하고 시스템 동작 줄이기를 반영한다.
- 제품 문구는 명사형·동사형이며 동사 관형형을 제거한다. 사용자 콘텐츠와 원본은 보존한다.

- 구현 전 이미지 생성 도구로 두 차례 시안을 생성해 사용자에게 표시했다. 최종 참고: `/Users/sion/.codex/generated_images/01a142e7-7894-71b3-a8b4-d068024d0a83/exec-4a0f6071-86d6-4f76-8afe-da39508a7600.png`.
- 이미지는 위계와 시각 방향의 참고이며 실제 문구·제품 동작 계약이 아니다.
- Luna low 독립 컨텍스트 1개에 코드·문서·정답 없이 문구와 기능 설명 5개 선택지를 전달했다. `정책 확인`의 보안 규칙 오해를 발견하고 `확인 질문`으로 교체해 재검사했다. `화면 구조`, `Figma 자료`, `확인 항목`, `프로젝트 규칙으로 저장` 등 핵심 용어의 의도 일치를 확인했다. 실제 사용자 조사로 일반화하지 않는다.

## 구현과 검증 계획

- 공통 토큰·컴포넌트, 웹 작업 공간, API·생성 흐름, 자료·설정, 플러그인을 소유 경로별로 병렬 구현한다.
- `append` 모드는 기존 replace/review와 호환하고 OpenAPI·양쪽 SDK를 재생성한다. DB 스키마 변경은 없다.
- 기존 저장·충돌·초안·복붙·키보드·한글 입력·XLSX 검증을 유지한다. 자동 추가·불확실 항목·플러그인 신규 동작의 회귀를 추가한다.
- 정적 검사·빌드, 실제 테스트 DB의 API, 브라우저 합성 및 실제 Figma 검증의 범위를 분리해 기록한다.

### 문구 검수

- 사용자 지정 Sol 독립 검수에서 저장 실패 후 항목 전환의 오류/복구 UI 소실, 에디터 하단 오류 잘림, 이미지 크기 및 관형형 잔존을 발견해 수정했다. 오류 조건·복구 행동·접근성 이름을 유지했다.
- 최종 스윕은 TSX뿐 아니라 모델/자동 저장/복붙/API 응답 문구까지 포함했다. API 오류 문자열17개를 정리했고 AI 시스템 프롬프트와 원본/사용자 콘텐츠는 보존했다.
- 검수자가 요청한 불필요한 일반 경고 추가는 없었다. 최종 잔존 내보내기 안내는 `시나리오 저장 후 다시 내보내주세요.`로 반영했다.
- 동일 Luna low 에이전트에서 추가8개 문구의 기능 이해를 검사했고 모두 의도와 일치했다. 독립 검수는 코드 기반이며 실제 브라우저 검증과 구분한다.
- 최종 화면 분석 레이아웃과 내보내기 안내의 범위 제한 재검수에서 추가 문제는 없었다.
