# 작업: 시안 기반 실제 프로젝트 리팩토링·리디자인

- 상태: 구현 중
- 사용자 지시: 2026-10-16 최신 시안들과 웹 프로토타입을 기준으로 현재 프로젝트를 리팩토링·리디자인한다.
- 기준 브랜치: `codex/mvp-generation`; 기준 HEAD `1009434b8570bdfe0ba9b2a4c0ada2adc9d8a21e`.
- 이전 독립 시안 변경을 보존한다. 사용자가 기존 백엔드·저장 기능 유지와 화면·흐름 개편을 선택했다. 실제 API·자동 저장·충돌 처리·업로드·XLSX 연결을 유지한다.
- 범위: 프로젝트/시트 목록, 표 편집, 드롭다운 설정, 상세 시트, 생성·후보 검토, 프로젝트 양식·IA, 업로드·플러그인, 시트 공유 열람의 시각·사용자 흐름 정리.
- 디자인: 표와 사용자의 주 작업을 넓게 배치한다. 추가 행동은 아이콘과 드롭다운·모달·상세 시트에 둔다. 한국어 용어와 사용자 설정 양식을 반영한다. 기존 이미지 생성 레퍼런스를 참고하며 개발 설명·브랜드 카피·메모리 초기화 경고는 넣지 않는다.
- 구조: 승인된 FSD 경로와 공통 UI 패키지 안에서 재사용 가능한 팝오버·아이콘·로딩 표현을 구현한다. 새 기능 폴더를 추가하지 않는다.
- 검증: 기존 저장·충돌·복붙·키보드 동작 유지, 브라우저에서 주요 화면·좁은 화면·설정·크기 조절 확인, 루트 lint/typecheck/build, 독립 UX 문구 검수. 실제 AI 호출과 외부 배포는 수행하지 않는다.

## 미정

- 기존 백엔드 유지 확정. 자동 검증에서는 실제 AI 서비스를 호출하지 않는다.
- 공유 링크의 외부 접근·유효기간·회수 정책은 기존 제품에서 미정이다. 정책을 임의 확정하지 않는다.
