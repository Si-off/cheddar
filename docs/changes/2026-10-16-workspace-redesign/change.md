## 적용한 화면과 책임

- 프로젝트 목록 → 시트 목록 → 표 편집으로 화면 깊이를 분리했다. 프로젝트·시트는 실제 API 데이터로 읽고 만든다.
- 시트의 주 화면은 전체 테스트 표다. 검색·보기 설정·행 추가만 표 도구로 두고 생성·후보 검토·XLSX·공유 시트 미리보기는 추가 메뉴에 배치했다.
- 보기 설정 → 레이아웃 → 표·QA 진행으로 이동한다. QA 진행은 전체 테스트 목록을 유지하며 여러 항목을 동시에 펼쳐 수행 내용을 읽고 편집으로 연결한다. 별도 QA 결과 저장 모델은 추가하지 않았다.
- 상세 편집은 옆에서 여는 모달 시트로 옮겼다. 셀·상세 편집은 기존 SheetSession을 공유한다. 자동 저장, revision 충돌 보호, 복붙·키보드·IME 조합·미저장 초안 복원과 이동 보호를 유지했다.
- 열 설정은 목록 → 해당 열의 이름·순서 드롭다운으로 구성했다. 열 너비는 표의 경계선에서 조절한다. 행 높이는 가로 경계선에서 늘리거나 줄이고, 더블클릭하면 내용에 맞는 높이로 복원한다.
- 새 프로젝트의 기본 표시 항목은 테스트 ID·기능 구분·테스트 항목·화면 ID·사전 조건·테스트 데이터·수행 절차·예상 결과다. 기능 구분·테스트 데이터는 기존 사용자 정의 텍스트 열 모델을 사용한다. 우선순위·관련 화면 시스템 필드는 추가 설정에 유지한다. 기존 프로젝트 양식·시트·사용자 지정 이름은 덮어쓰지 않는다.
- 프로젝트 설정은 드롭다운으로 기본 정보·IA 관리·기본 양식을 선택한다. 양식의 이름·순서는 열별 드롭다운, 기본 너비는 양식 미리보기 표의 경계선에서 편집한다. 변경은 이후 새 시트에만 적용된다.
- 업로드 목록·화면 갤러리를 정리하고 새 시트 만들기를 모달로 옮겼다. 플러그인은 화면 목록 확인 → 업로드할 프로젝트 지정으로 나눈다. 화면 미리보기는 실제 프레임 내보내기 메시지를 사용한다. 기존 업로드 세션·등록 확인·실패 복구 로직과 플러그인 ID `1692417282897261384`는 유지한다.
- 공유 시트 미리보기는 현재 시트 전체 테스트를 읽기 전용으로 표시한다. Figma 화면 이미지·프레임 미리보기를 공유하지 않는다. 사용자 열 이름과 순서·텍스트 값을 반영한다.
- 공통 팝오버·아이콘은 `packages/ui/src/`, 화면 공통 표현은 `apps/web/src/shared/ui/`, 열 설정은 `widgets/test-case-table/`에 분리했다. 제품은 독립 프로토타입 소스나 모킹 데이터에 의존하지 않는다.

## 디자인 기준과 참고

기존 디자인 토큰을 사용했다. 기본 화면은 넓은 표와 여백에 집중하고 추가 행동은 드롭다운·모달·상세 시트에서 제공한다. 로딩 스켈레톤, 생성 상태, 짧은 색상·투명도 전환을 적용했다. 브랜드 카피·메모리 초기화 경고·개발 설명은 넣지 않았다.

이 대화의 이미지 생성 도구로 만든 로컬 레퍼런스 중 표·드롭다운 요소·프로젝트와 양식·작업 상태·플러그인·시트 공유 보드를 참고했다. 이미지 자체를 제품의 UI나 배경으로 넣지 않았다. 기존 독립 시안 소스와 전용 빌드 설정은 작업 시작 시 미커밋 상태였으며 이번 제품 변경과 분리해 로컬에 보존했다.

## 검증 근거

- 루트 `pnpm check`: lint·전체 타입 검사·제품 빌드 통과. 기존 파일 크기·청크 크기·optional chain 권고는 오류와 구분했다.
- API 실제 PostgreSQL·HTTP 검사: 56개 통과. 전용 `cheddar_stage1_test` DB만 사용하고 이 실행의 UUID 데이터와 OS 임시 파일을 정리했다. 실제 AI 서비스는 호출하지 않았으며 생성 응답은 테스트 대역을 사용했다.
- 실제 제품 편집기 Chrome 검사: 22개 통과. 생성 초기 잠금·교체 확인·후보 추가, 저장 응답 지연·충돌·초안 복원, 복붙·키보드, 500행 편집·검색, 표·QA 목록·공유·모바일 화면을 포함한다. 최종 보완한 행 높이 축소·복원과 공유창 표시도 별도 검사 2개로 재확인했다.
- 프로젝트 설정 Chrome + 실제 API/DB 검사: 13개 통과. 드롭다운 이동, 저장·충돌·지연 조회 보호, IA 계층·중복·참조 삭제 제한, 기본 양식의 새 시트 적용·기존 시트 보존, 경계선 너비 조절을 확인했다.
- 플러그인 UI Chrome 검사: Figma 메시지 모의 환경에서 화면 확인·실제 UI 이미지 미리보기·프로젝트 지정 1개 통과. Figma bridge·메인 선택/내보내기·업로드 세션 Node 검사 13개 통과.
- 실행 중인 기존 로컬 백엔드에 연결한 웹에서 실제 프로젝트·시트 목록과 저장된 기존 시트 열람을 확인했다. 실제 사용자 시트 내용은 수정하지 않았다.
- 브라우저 화면은 OS 임시 경로 `/private/tmp/cheddar-redesign-last-results/`, `/private/tmp/cheddar-redesign-editor-final/`, `/private/tmp/cheddar-redesign-settings-results/`, `/private/tmp/cheddar-redesign-plugin-results/`에서 확인했다. 검증 로그도 `/private/tmp/cheddar-redesign-*.log`에 둔다.
- 기존 테스트에서 제거된 너비 숫자 입력·상시 도구·탭의 조작은 실제 드롭다운·경계선 조작으로 바꿨다. 저장·충돌·오류 보존 검증은 유지했다. 기본 양식 변경에 따른 fixture와 열 개수만 새 계약에 맞췄다. 원격 main이 추가한 생성·후보 검토 검증도 보존했다.
- 지정 독립 UX 문구 검수: 실제 제품의 신규 문구·표시 조건을 코드 기반으로 검수했다. 미지원 공유 링크 요청 문장을 삭제했고 양식 미리보기에 시각적 캡션을 추가했다. 최종 재검수 문제 없음. AI 전송 범위, 기존 내용 교체, 저장 실패·충돌과 공유 읽기 전용 표시는 필요한 정보로 유지했다.

## 남은 범위와 실행 상태

- 실제 공유 링크 발급·외부 열람, IA 파일 분석·플로우 분석 API는 기존 후속 범위다. 이번 UI 리팩토링에서 계약이나 백엔드를 새로 만들지 않았다.
- 보기 전환·열 숨김·행 높이는 열린 편집 화면의 표시 상태다. 서버의 업무 내용·열 이름·순서·너비와 구분한다.
- 실제 AI 응답 품질 및 리디자인 후 Figma 데스크톱·브라우저 호스트 안의 실행은 이 작업에서 확인하지 않았다. 플러그인 UI 메시지 환경과 기존 핵심 프로토콜 검증으로 한정한다.
- 원격 main의 Windows 저장 경로 보완을 통합했다. 제품 정책·AGENTS·디자인 토큰 원본을 변경하지 않았다.
- 이 작업에서 실행한 검증용 개발 서버는 종료한다. 기존에 실행 중이던 백엔드 프로세스는 건드리지 않는다.
