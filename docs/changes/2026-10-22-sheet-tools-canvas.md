# 작업: 헤더 정리, 셀 도구 막대, 캔버스 보기

여러 세션에 걸치는 작업이다. 시안 기준은 Design 캔버스 "Cheddar 화면 시안"(https://claude.ai/artifact/LBfqbThAA8AGkkAYd8BNdA) 테스트 세트 페이지다. 끝나면 이 파일을 지우고 남길 결정은 product/architecture로 옮긴다.

## 목표

- 웹과 플러그인 헤더에서 "Cheddar" 타이틀을 뺀다.
- 테스트 세트 상단을 제목 줄과 도구 상자 하나로 정리한다.
- 표 편집 기능을 Google 스프레드시트와 같은 이름, 동작, 단축키(Mac·Windows)로 맞추고 셀 도구 막대를 둔다.
- 카드 보기와 묶기 기준을 없애고 캔버스 보기(줌, 그룹화, 간략/상세)로 바꾼다.

제외: 폰트·서식 기능, 정렬·필터, 틀 고정, 목록 밖 값을 목록에 바로 추가하는 기능(노션식).

## 확정한 결정 (2026-10-22)

- 기준 도구는 Google 스프레드시트다. 메뉴 문구는 Sheets 한국어 UI, 단축키는 Mac(⌘)과 Windows(Ctrl) 모두 Sheets와 같게, 표시는 사용자 OS에 맞춘다. 제품 문서의 "Excel처럼" 규칙도 Sheets 기준으로 바꾼다.
- 목록 밖 값(드롭다운 항목에 없는 값)은 타이핑, 붙여넣기, 항목 변경 모두 허용하고 셀 오른쪽 위에 빨간 삼각 표시를 단다. 안내 문구는 없다.
- 상단 배치: 제목 줄은 제목, 저장 상태, 공유. 그 아래 도구 상자 하나에 `표 | 캔버스` │ 보기별 도구 │ 케이스 추가 생성, XLSX 내보내기 ··· 검색, 확인 필요.
- 셀 도구(표): 실행취소 ⌘Z, 재실행 ⌘Y │ 수정 ▾ │ 삽입 ▾ │ 셀 병합 ▾. 그룹은 아이콘과 ▾, 메뉴 맨 위에 그룹 이름.
  - 수정: 잘라내기 ⌘X, 복사 ⌘C, 붙여넣기 ⌘V │ 아래로 채우기 ⌘D, 행 위로 이동, 행 아래로 이동 │ 값 삭제 Delete, 행 삭제 │ 찾기 및 바꾸기 ⇧⌘H(Windows Ctrl+H)
  - 삽입: 위에 행 1개 삽입, 아래에 행 1개 삽입
  - 셀 병합: 세로로 병합, 병합 취소
  - 우클릭 메뉴도 같은 이름과 단축키를 쓴다.
- 캔버스 보기: 그룹마다 세로 열(B안). 확대율로 내용이 바뀌지 않고, 표시(간략/상세)와 그룹화(기능 그룹 기본, 테스트 환경, 사용자/관리자, 없음)를 도구 상자의 아이콘 드롭다운으로 고른다. 결과 색과 결과 요약은 양식에 "결과" 열(`qa_result`)이 있을 때만 켠다. 상세 카드 안의 항목은 표처럼 이름 칸 회색, 값 칸 흰색이고 그 자리에서 편집한다. 캔버스 상자는 흰색, 카드는 테두리 없는 연회색, 왼쪽 색 띠 없음. 결과 요약은 캔버스 왼쪽 아래, 확대·축소는 오른쪽 아래.

## 구현 순서 (PR 단위)

1. **헤더 정리** (웹·플러그인)
   - `apps/web/src/widgets/app-header`, `widgets/auth-card`, `pages/shared-test-set`, `apps/figma-plugin/src/ui/shared/ui/plugin-shell.tsx`, `ui/pages/login`에서 타이틀 제거.
   - 플러그인에서 헤더에 남는 것이 없는 화면은 헤더 줄을 없앤다. "Cheddar 열기" 같은 버튼 문구와 오류 안내는 대상이 아니다.
2. **셀 도구 막대와 이름·단축키** (`widgets/case-table`, 필요하면 `packages/ui` Menu 확장)
   - 지금 있는 기능만 먼저 막대와 우클릭 메뉴로 옮기고 이름을 Sheets에 맞춘다(셀 나누기 → 병합 취소 등).
   - 단축키 표시는 OS 감지로 바꾼다.
   - 목록 밖 값: 타이핑 허용, 빨간 표시. 웹 셀 편집기와 `set_cell` 검증을 확인한다.
3. **새 편집 기능**
   - 범위 선택(끌기, Shift+클릭, Shift+방향키). 아래로 채우기와 세로로 병합의 전제다.
   - 실행취소·재실행: 클라이언트 작업 기록에 역연산을 쌓아 기존 `ops` API로 되돌린다. 공동 편집 중 남의 변경과 충돌하는 규칙을 정한다.
   - 잘라내기, 아래로 채우기, 행 위·아래 이동(`move_case` 재사용), 찾기 및 바꾸기, 세로로 병합(선택 범위를 맨 위 값으로 채움).
4. **캔버스 보기와 상단 배치** (`widgets/case-board`를 캔버스 위젯으로 교체, `pages/test-set`, `features/test-set-view`)
   - 상단 도구 상자로 재배치하고 묶기 드롭다운을 없앤다.
   - 보기 설정 계약 변경: `view` `table|card` → `table|canvas`, 표시 `brief|detail` 추가, `groupByColumnId` → 그룹화 기준(기능 그룹·열·없음). 기존 `card` 저장값은 `canvas`로 옮긴다.
   - 줌과 이동: Figma 문법(⌘/Ctrl+휠 확대, 휠·스페이스 끌기 이동), 확대율 표시.
   - 결과 요약 누르면 해당 결과만 또렷하게, 나머지는 흐리게.
   - API(`apps/api`, Codex 위임 가능): 케이스별 기능 그룹 저장(아래 결정 1: 마이그레이션, 생성 결과 저장, `add_case` 상속, 그룹 변경 연산, 공동 편집 전파), 보기 설정 DTO, OpenAPI 재생성.
5. **문서**
   - `docs/product.md`: 용어(보기, 묶기 → 그룹화, 카드 보기 → 캔버스), 표 보기 규칙의 Excel → Sheets, 목록 밖 값.
   - `docs/architecture.md`: 보기 설정과 기능 그룹 저장.
   - `DESIGN.md`: 새 토큰이 생기면 맥락 한 줄.

PR마다 `pnpm check`, 관련 테스트(`pnpm test:api`, 웹 e2e), `pnpm dev:web` 실제 화면 확인, UX 문구 검수 에이전트, `/codex:review`를 거친다.
