# 제품 정의

이 문서는 현재 합의된 제품의 기준이다. 개별 작업의 계획이나 아이디어를 확정된 제품 요구사항으로 취급하지 않는다.

## 제품 목적과 범위

Cheddar는 사람이 수행하는 QA 테스트 케이스를 AI로 생성하고, 편집·공유·XLSX 내보내기 할 수 있는 제품이다.

- 단위 테스트 케이스: 개별 화면·기능을 대상으로 사람이 수행하는 QA 케이스.
- 통합 테스트 케이스: 여러 화면에 걸친 사용자 흐름을 대상으로 사람이 수행하는 QA 케이스.

이 구분은 제품 안에서 작성하는 QA 케이스의 범위를 뜻한다. 프로젝트 코드의 단위·통합 테스트 도구 선택을 의미하지 않는다.

## 구성요소별 역할

| 구성요소 | 확정된 역할 |
| --- | --- |
| Figma 플러그인 | 선택한 Figma 프레임의 데이터·이미지 업로드에 집중 |
| 웹 | AI 테스트 케이스 생성·편집, 공유와 XLSX 내보내기 제공 |
| 백엔드 서버 | 필요한 구성요소이며 구체적인 책임과 구현은 별도 설계 |

## 편집과 공유

- 편집 UI는 엑셀 같은 표 중심으로 구성하며 긴 내용은 상세 패널에서 수정한다.
- 팀·개인별 작성 방식에 대응하는 구성 자유도와 인터랙션을 지향한다. 구체적인 사용자 정의 범위는 미정이다.
- 공유는 링크 열람 방식이며 초기 공유 링크는 읽기 전용이다.
- 링크별 편집 권한 지원은 향후 범위다.

## 초기 검증 환경

- 로그인과 검색 노출 없이 개발자 PC에서 로컬 검증한다.
- 백엔드와 DB도 로컬에서 실행한다.
- 사내 배포는 추후 결정한다. 로컬 링크 열람의 구체적인 접근 범위와 연결 방식은 미정이다.

## 갱신 기준

사용자가 결정한 내용을 반영하고, 관련 작업이나 결정 기록이 있으면 연결한다. 제안과 미해결 질문은 확정 항목에 섞지 않는다. 기존 결정을 바꾸면 현재 내용과 결정 근거를 함께 갱신한다.
